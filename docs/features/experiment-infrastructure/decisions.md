## 2026-10-09：整理既有约定

来源：原有项目文档和本次沟通；此日期是整理日，不追认历史决定的发生日期。

决定：区分 split seed 与 training seed；当前深度模型固定五个训练 seeds。可比实验保持既定精度和预算；单次传统模型不伪造多 seed 标准差。

原因：保留方法本身与项目实验协议，避免实现差异、数据泄漏或统计口径造成错误比较。

影响：新增实验应遵守这些约定；若确需变化，追加决定，说明替代哪一项及对应实验。

证据：[功能说明](README.md)、[实施记录](tasks.md)。
