# 决策

- 使用独立 protocol_id，旧 gap 和多任务的规则不被放宽。
- 原始 CSV 标签保留物理单位；数据审计中的 target_scaling=none 表示磁盘存储，神经网络训练时另外拟合 Z-score。
- token ID、原子类别不做统计 Z-score；几何坐标保持原单位和模型既有处理。
- 新六性质 min_delta=0，避免跨物理单位沿用 1e-5 Hartree 的阈值。
- Infomax 只复用同划分、同 seed、同几何的自监督权重；六性质的下游模型独立初始化和微调。
- 每张卡运行一个独立任务，不使用 DDP；任务、状态和结果持久化，不依赖对话保活。
- 仅支持队列级恢复：已完成任务跳过；中断任务保留现场，通过明确重试从头运行。不宣称优化器级断点续训。

- 原七个 QM9 适配器的历史 gap 为 MAD+MAE；本次新增六性质为 Z-score+MSE。原表保留历史记录，不宣称两批 loss/scaler 相同。
- Infomax 默认 auto 查找匹配权重；显式路径校验失败直接报错，复用权重保存 SHA256 并在训练时复核。
- 完整任务配置及模板快照落盘后冻结；修改源文件需要生成新批次。

- 跨机使用用户指定的高/中/低静态互斥分组，分别 54/72/54 项，共用训练协议。
- 分组清单独立保存至 groups/*.yaml，组内用已有 3090 单 epoch 烟测安排优先级和 LPT 分卡。
- 调度权重不作为其他 GPU、新性质或早停后的准确耗时预测；Chemprop 计时含启动和特征化。
- 结果先在来源机器验证预测，再复制报告到本地核对哈希、数据身份、单位和多 seed 统计；不引入跨机常驻调度服务。
