# 最终审查

## 范围和口径

- 十模型 × 六性质 × 三 seed，180 个下游任务，输出目录互不重叠。
- 沿用 QM9 既有 split manifest、样本顺序与原单位标签。三维模型复用既有坐标及原子序列。
- 新六性质统一训练集 Z-score、MSE、原单位验证 MAE 选模，256/100/20，min_delta=0。
- 旧 gap 和三任务协议仍严格校验，不因本功能接受其他目标；旧结果不改写。
- Infomax 同 seed/manifest/geometry 权重可自动复用，显式指定的不兼容权重拒绝复用。复用权重保存 SHA256，训练前再次核验。
- 每个 seed 的六项下游任务独立训练；共享的仅是该 seed 的自监督初始化。

## 已验证

- 分组验证覆盖 75 项不同的测试，包含既有 gap、SPE 多任务和物理约束的相关回归检查。
- 七个图适配器的真实 CPU 前向、非能量目标的 MSE 反向、有限梯度与权重保存/重载通过。Infomax 此项只检验随机初始化的网络，不代表实际预训练权重验收。
- Chemprop 用 mu 完成小样本训练、预测和原单位评测，模型内 scaler 与训练集统计量一致。实际停止 epoch 从 last.ckpt 获取，而非 best epoch。
- 两个序列 Transformer 用 alpha 完成小样本单 epoch 训练，保存 tokenizer/scaler，重新加载权重后预测一致。
- QM9 公共训练入口用 SchNet/alpha 完成小样本训练，核对目标读取、逆变换和指标。
- 已验证失败任务继续下一项、再次启动跳过已完成项、重试保留旧输出、共享 RAM 不足时禁止启动、原单位 CSV 重算和三 seed 样本标准差。
- LaTeX 导出需完整 60 组摘要，填入 60 个新单元格，保留已有 ML、gap 和时间列。没有真实新结果时拒绝填表。
- 仅用待提交补丁在干净 HEAD 副本运行 36 项检查通过，确认不依赖工作区其他未提交功能。
- Ruff、差异空白检查、源文件大小和敏感信息扫描通过；数据、权重、outputs 不在提交范围。

实际本地完整矩阵及原表 hash 见 matrix_audit.json；模型模板来源见 model_config_sources.json。

## 验收边界

- 正式 180 项训练未启动；/tmp 原表没有填入虚构数值。
- 本地 sandbox 无可用 CUDA/NVML，本次完成的是 CPU 小样本与静态审查。目标服务器上的 GPU、batch256 峰值、实际并发吞吐和正式精度仍待验收。
- 资源准入使用历史 gap 测量，不保证不同硬件/库版本的显存完全相同。OOM 单任务失败后继续，不自动改变 batch256。
- 默认一任务一张卡，无 DDP。队列可恢复，单项重试从头训练，不支持恢复优化器状态。
- 旧七个 QM9 适配器 gap 使用 MAD+MAE；新六性质使用 Z-score+MSE。跨性质、跨单位和跨机器耗时不作严格横向比较。
- 预测误差使用原单位；MSE 的单位是目标单位的平方。
