# 工作三：电镀添加剂智能筛选系统

**状态**：设计阶段

## 1. 动机与问题定义

### 1.1 电镀添加剂筛选的现实需求

**背景**：
- 电镀工艺（铜镀层 → 钴镀层过渡）需要寻找新的添加剂（整平剂、光亮剂）
- 传统方法：实验试错，周期长（数月）、成本高（数万元/轮）
- 候选分子库巨大（10⁵–10⁶ 量级），无法全部实验验证

**计算化学的困境**：
- DFT 计算精确但慢（每个分子数小时）
- 经验筛选（QSAR）不可靠，无法预测新骨架

**工作一和工作二解决了什么**：
- 工作一：纯 2D（只需 SMILES）快速预测分子量子化学性质
- 工作二：有 3D 坐标时，精度逼近 DFT（但快 100 倍）

**但它们没解决**：
1. 化学家不懂如何调用模型
2. 没有"SMILES → 自动 3D 构象 → 预测"的端到端流程
3. 没有将预测结果映射到"是否适合做添加剂"的领域知识

**工作三的定位**：
> 构建一个 **LLM 驱动的智能体系统**，让化学家用自然语言描述需求（如"找铜电镀整平剂"），系统自动调用工作一/二的模型，结合领域知识库，给出候选分子排序和解释。

### 2.2 为什么这个联系是"连贯"的（答辩时怎么讲）

**评委质疑**："前两个工作是算法，第三个是系统，这不是三篇论文拼接吗？"

**回答**：
1. **工作一、二是 通用方法**，需要在 **特定领域** 验证泛化能力 → 工作三是验证载体
2. **工作三的核心挑战不是"套壳调用"**，而是：
   - **输入适配**：SMILES → 自动 3D 构象生成（RDKit ETKDG vs 无构象）
   - **路由策略**：何时用 2D（快）、何时用 3D（准）？需要 trade-off
   - **输出解释**：7 个量子化学性质 → 电镀添加剂适用性（需要领域知识建模）
3. **LLM 不是多余的包装**，而是：
   - 自动推理用户意图（"整平剂" → 需要哪些性质约束）
   - 动态调用工具链（SMILES → 3D → 模型 → 筛选）
   - 生成可解释的报告（为什么推荐分子 X）

**类比**：AlphaFold 论文 = 算法 + 蛋白质结构数据库应用；你的论文 = 算法（工作一、二）+ 电镀添加剂筛选应用（工作三）

┌─────────┐      ┌──────────┐  ┌──────────┐ ┌─────────┐

### 3.2 核心模块

#### 模块 1：SMILES 标准化与验证
- 输入：用户提供的 SMILES（可能非规范）
- 工具：RDKit `MolStandardize`
- 输出：规范 SMILES + 有效性标记

#### 模块 2：3D 构象生成（路由决策）
**决策点**：何时生成 3D？

**策略 A（保守）**：所有分子都生成 3D，调用工作二（λ=1）
- 优点：精度最高
- 缺点：慢（每个分子 +5 秒构象生成 + +2 秒推理）

**策略 B（激进）**：都不生成 3D，只用工作二（λ=0）
- 优点：最快
- 缺点：精度受限

**策略 C（自适应，推荐）**：
1. 先用工作二（λ=0）快速预测所有分子
2. 根据性质约束，筛选出候选（前 20%）
3. 只对候选生成 3D，用工作二（λ=1）精确预测
4. 结合两次预测的不确定性，给出最终排序

**工具**：
- RDKit `AllChem.EmbedMolecule` (ETKDG)
- 可选：MMFF 优化（+10 秒/分子）

#### 模块 3：预测模型调用
**接口**：
```python
def predict(smiles: str, coords: Optional[np.ndarray] = None) -> Dict[str, float]:
    """
    调用工作二的统一框架

    Args:
        smiles: 规范 SMILES
        coords: 3D 坐标 (N, 3)，None 则自动 λ=0

    Returns:
        {'homo': -6.2, 'lumo': -1.8, 'gap': 4.4, 'mu': 3.5, ...}
    """
    if coords is None:
        model = load_model("work2_lambda0")  # 纯 2D
    else:
        model = load_model("work2_lambda1")  # 3D
    return model.predict(smiles, coords)
```

#### 模块 4：领域知识库

**知识库内容**：

**表 1：电镀添加剂类型 vs 量子化学性质约束**

| 添加剂类型 | HOMO (eV) | LUMO (eV) | μ (Debye) | α (Å³) | 物理依据 |
|---|---|---|---|---|---|
| 整平剂 | -6.5 ~ -5.5 | > -2.0 | > 2 | 10-20 | 需吸附在凸起处，抑制过度生长 |
| 光亮剂 | -7.0 ~ -6.0 | -3.0 ~ -2.0 | < 1.5 | 5-15 | 紧密吸附，降低表面粗糙度 |
| 抑制剂 | < -7.0 | < -3.5 | 任意 | > 20 | 强吸附，全面抑制沉积 |

**表 2：金属体系差异（铜 vs 钴）**

| 金属 | 工作电位 (V vs SHE) | 添加剂 HOMO 偏好 | 说明 |
|---|---|---|---|
| 铜 | +0.34 | -6.0 ~ -5.5 | 贵金属，较高 HOMO 易吸附 |
| 钴 | -0.28 | -6.5 ~ -6.0 | 活泼金属，需更强吸附 |

**实现**：
- 方案 A（简单）：硬编码规则（`if-elif-else`）
- 方案 B（可扩展）：向量数据库（Chroma / FAISS）+ LLM 检索增强生成（RAG）

## 4. 实验设计

### 4.1 数据集

**候选分子库**：
- 来源 1：商业化学品数据库（Sigma-Aldrich / TCI）中筛选含 N/S/O 杂原子的小分子（< 500 Da）
- 来源 2：文献中报道的电镀添加剂（约 50-100 个已知有效分子）
- 来源 3：生成式模型（如 SMILES LSTM）生成的新骨架

**规模**：初步 1000-5000 个分子

### 4.2 评估指标

**系统性能**：
- **吞吐量**：每秒处理分子数（2D vs 3D 模式）
- **端到端延迟**：从 SMILES 输入到结果输出的时间

**预测准确性**：
- 对已知有效添加剂（文献中的正例），系统排序的 Recall@10 / Precision@10
- 对 QM9 测试集，性质预测的 MAE（验证工作二的准确性在新分子上保持）

**可解释性**（定性）**：
- LLM 生成的推荐理由是否符合化学直觉
- 化学家评估：5 分李克特量表（1=完全不可用，5=可直接用于实验）

### 4.3 消融实验

| 配置 | 路由策略 | LLM | 知识库 | 目的 |
|---|---|---|---|---|
| Baseline | 都用 2D | ❌ | ❌ | 纯模型预测 + 硬编码规则 |
| +3D | 自适应 | ❌ | ❌ | 量化 3D 的价值 |
| +LLM | 自适应 | ✅ | ❌ | 量化 LLM 编排的价值 |

## 5. 与工作一、二的形式化关系（答辩时的严格表述）

### 5.1 模型复用

设工作二的模型为 $f_\theta: (\text{SMILES}, \{\mathbf{r}_i\}, \lambda) \to \mathbb{R}^7$

工作三定义两个特化版本：
$$
f_{\text{2D}}(\text{SMILES}) := f_\theta(\text{SMILES}, \varnothing, 0)
$$

$$
f_{\text{3D}}(\text{SMILES}, \{\mathbf{r}_i\}) := f_\theta(\text{SMILES}, \{\mathbf{r}_i\}, 1)
$$

### 5.2 路由策略形式化

设筛选任务为 $T = (\mathcal{S}, \mathcal{C})$，其中：
- $\mathcal{S} = \{\text{SMILES}_1, \ldots, \text{SMILES}_N\}$ 是候选分子集
- $\mathcal{C}$ 是性质约束（如 $-6.5 < \text{HOMO} < -5.5$）

**策略 C（自适应）**：
1. **阶段 1（粗筛）**：
   $$
   \hat{\mathbf{y}}_i^{\text{2D}} = f_{\text{2D}}(\text{SMILES}_i), \quad i = 1, \ldots, N
   $$
   
   $$
   \mathcal{S}_{\text{cand}} = \{i : \hat{\mathbf{y}}_i^{\text{2D}} \text{ 满足 } \mathcal{C}\}
   $$

2. **阶段 2（精筛）**：对 $i \in \mathcal{S}_{\text{cand}}$，
   $$
   \{\mathbf{r}_i\} = \text{ETKDG}(\text{SMILES}_i)
   $$
   
   $$
   \hat{\mathbf{y}}_i^{\text{3D}} = f_{\text{3D}}(\text{SMILES}_i, \{\mathbf{r}_i\})
   $$

3. **排序**：
   $$
   \text{score}_i = \text{Fitness}(\hat{\mathbf{y}}_i^{\text{3D}}, \mathcal{C}) - \alpha \cdot \text{Uncertainty}(\hat{\mathbf{y}}_i^{\text{3D}})
   $$

**复杂度分析**：
- 策略 A（全 3D）：$O(N \cdot T_{\text{3D}})$
- 策略 C（自适应）：$O(N \cdot T_{\text{2D}} + |\mathcal{S}_{\text{cand}}| \cdot T_{\text{3D}})$

若 $|\mathcal{S}_{\text{cand}}| \approx 0.2N$，且 $T_{\text{3D}} \approx 10 \cdot T_{\text{2D}}$，则策略 C 约为策略 A 的 **30%** 时间。

### 5.3 工作三的独立贡献（不只是"调用"）

1. **3D 构象生成的误差传播**：ETKDG 生成的构象与 DFT 构象的差异，如何影响工作二的预测？需要实验量化。
2. **多目标优化**：电镀添加剂需要同时满足多个性质约束（HOMO/LUMO/μ/毒性/成本），如何设计 Pareto 最优筛选？
3. **领域知识建模**：如何将电化学文献中的定性规则（"整平剂需要选择性吸附"）量化为可计算的约束？

## 7. 关键技术风险与应对

| 风险 | 应对 |
|---|---|
| ETKDG 构象不准 | 只用 MMFF 优化；或用工作二（λ=0.5）作为鲁棒版本 |
| LLM 幻觉 | 所有工具调用结果需验证；关键决策（如约束）记录日志供人工审核 |
| 知识库覆盖不足 | 提供 fallback：当规则不匹配时，LLM 提示"需要人工指定约束" |
| 评估缺少真实实验 | 至少在文献已知正例上验证排序性能（Recall@K） |
