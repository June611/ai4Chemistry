## 目标

将不同方法接入本项目，在同一任务下进行可追溯的实验比较。一个仓库共享数据和评估接口，
各方法保留独立实现、配置、上游版本及必要依赖；不要求全部使用 Chemprop 网络。

## 接入验收

1. 记录论文、源码地址、固定 commit/版本、许可、输入要求及预训练权重来源。
2. 明确是论文原设定复现，还是迁移到 QM9 的方法适配；列出所有偏离。
3. 复用已确定的样本划分，禁止在验证/测试集拟合分词、scaler 或特征选择。
4. 为方法添加独立代码/适配层和 YAML，避免复制整个项目或混改第三方源码。
5. 验证关键算法行为、梯度/小样本拟合（适用时）、保存恢复和指标重算。
6. 按已约定预算执行正式实验，输出 sample_id 对齐的预测及统一指标。
7. 报告结果、统计范围和局限；无结果的模型保持待完成，不填推测数值。

若论文方法只能使用独立依赖环境，在同一仓库提供独立环境配置和转换入口，
通过稳定的数据/预测文件接口接入，不强迫升级所有已有模型的依赖。

原论文复现实验与统一 QM9 对照实验分别配置和报告。
多任务模型使用额外的 homo/lumo 监督，外部预训练也提供额外信息，比较表必须明确标注。
