# 物理模块设计草案：不把恒等式和不等式混为一谈

本页是已编码的物理约束规范，不代表已验证精度收益。QM9的总分子能量与原子化能量不能混用。

网络结构、十任务监督、残差容差、候选归一化公式、物理权重预热与接入验收，已补入[训练清单中的PINN详细方案](model_and_module_lists.md)。其中超参为已写入配置的初始方案；本页主要保留关系适用条件和已有数据审计证据。

| 约束 | 数学残差/违约量 | 所需预测 | 适用条件 |
|---|---|---|---|
| 轨道能隙 | r_g=gap−(LUMO−HOMO) | 原七任务已有三项 | 相同计算级别及Hartree；打印舍入需容差 |
| 焓与内能 | r_h=H298−U298−kBT | 新增U298、H298 | 298.15K、理想气体总分子能量；每分子用kBT，不用摩尔RT数值直接相加 |
| 热能增量非负 | v_t=max(U0−U298,0) | 新增U0、U298 | QM9平衡态热化学校正约定；这是不等式，不是等式 |

原始133885条QM9标签审计：gap残差绝对值最大约1e-4 Ha；H−U约0.000944186 Ha，打印舍入后的残差小于1e-6 Ha；U298−U0最小0.002518 Ha，本地全表无非负性违约。数值细节及数据SHA256见[审计JSON](verification/qm9_physical_relations.json)。这只是关系/单位检查，权重及归一化尺度仍仅用训练集或预先指定，不从全表或测试集拟合。

候选soft loss为监督MSE加上归一化的物理残差平方；先将各预测按自己的train scaler逆变换，在float64中计算能量差，再使用训练集/预先声明的正尺度归一化。不要用接近0的真实恒等式残差标准差直接除法，避免数值放大；舍入容差与权重已在当前配置冻结。所有物理参数只用验证集比较，不通过测试RMSE调节。

当前用户选择整体效果验证，PhysicsGap7和MTL10-control不进入默认执行清单；PhysicsThermo10与原骨干历史/新基线比较时，必须披露额外标签与联合监督的变化，不能把全部收益单独归于物理正则化。若后续要求独立归因，再补同架构十任务无约束对照。各热化学关系通过共享编码器间接影响gap，是否有利尚无证据；H−U约束本身没有直接给出gap的新方程。

不采用U0=ZPVE（缺少电子能项），不采用gap=HOMO−LUMO。标准CSV没有独立熵S；从H和G派生S后再用G=H−TS没有新增独立约束。原子化能与元素参考能关系可作为后续候选，但需要核实参考表、单位、化学计量和标签派生来源，不能现在宣称已实现第三条独立等式。

数据与物理约定来源：[QM9原始数据论文](https://www.nature.com/articles/sdata201422)、[Gaussian官方热化学说明](https://gaussian.com/wp-content/uploads/dl/thermo.pdf)。当前核查支持上述关系适用性，不支持预测精度已经提升。
